# StoryDash_2026
Dashboard project submitted for the StoryDash 2026 competition organized by the Stat Circle of University of Colombo.

Along with my teammate Keshine Kamalakkannan, we created Dengue Surveillance dashboard using data from the period 2010-2020. We analysed how the cases have been affected by climatic factors, such as rainfall and temperature for 26 health regional districts of Sri Lanka.
